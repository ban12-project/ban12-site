# Content repository

- `pages/<locale>/<section>/<slug>.md`: preferred format for agent-written articles.
- `pages/<locale>/<section>/<slug>.mdx`: reviewed MDX, including unchanged legacy content.
- `countries.json`: all original country records, generated by the initial import.
- `migration.json`: read-only migration provenance and legacy URL baseline.
- `templates/article.md`: unpublished authoring template, excluded from routing.

No live data is bundled in this preparation patch. `countries.json` and `pages/`
are deliberately absent until the real export is imported. Empty placeholders and
sample travel articles are not a substitute for the original dataset.

Files use `---` delimiters with **strict JSON frontmatter** (a YAML-compatible
subset). Body text is stored separately from metadata and never rewritten by the
importer. File paths must exactly match the frontmatter `path`.

A content commit is the publishing mechanism: review the PR, validate it, and
redeploy. Runtime edits, database URLs and remote content fetches are not used.
